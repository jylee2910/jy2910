# CRYSTAL ECHOES (크리스탈 에코즈)

HD-2D 스타일 JRPG 프로토타입입니다. 도트 스프라이트를 3D 디오라마 위에 올리고 피사계심도·블룸·컬러 그레이딩을 입혔습니다. 『파이널판타지 브레이브 엑스비어스 레조넌스』 류 시스템(타임라인 커맨드 배틀, 브레이크 → 풀 브레이크 → 엑스트라 페이즈, 전설 영웅 「에코」 장착과 레조넌스 필살기)을 복각했고, 캐릭터와 세계관은 오리지널입니다.

이번 볼륨은 이후 챕터를 붙이기 위한 토대입니다. **프롤로그부터 1장(튜토리얼)까지**만 들어 있습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 빌드 (상대 경로, 어디든 업로드 가능)
```

### 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 · 커서 |
| Enter / Space / Z | 결정 · 조사 · 대사 넘기기 |
| X / Esc / Backspace | 취소 |
| Shift | 달리기 |
| M / Tab | 메뉴 (장비 & 에코 / 아이템 / 기록) |
| F | 전투 배속 |

게임패드와 터치(가상 스틱)도 지원합니다.

### 디버그 URL 파라미터

- `?battle=wolves` / `?battle=boss&echo=1`: 해당 전투로 바로 진입 (`TROOPS` 참고)
- `?scene=field&flags=field_start,imp_ambush&pos=24,8`: 필드의 특정 위치·진행도에서 시작
- `?scene=castle`: 알현실 이벤트
- `&auto=1`: 자동 전투와 대사 자동 진행
- `&dt=3`: 시간 배속 (헤드리스 캡처용)

## 1장 흐름

1. 타이틀 → 프롤로그 내레이션
2. **알현실**: 국왕의 명으로 신전 조사를 맡고, 아르젠이 합류합니다.
3. **필드 튜토리얼**: 이동, 목표 표시, 미니맵, 심볼 인카운터
4. **임프 습격**: 전투 기본 튜토리얼 (타임라인, 커맨드, 적 게이지)
5. **미라 & 넬 구출**: 브레이크 / 풀 브레이크 / 엑스트라 페이즈 튜토리얼, 4인 파티 완성
6. **고대 신전**: 에코 리리엘·볼테르를 획득하고 장착 튜토리얼 메뉴를 엽니다.
7. **보스 「고룡 그림윙」**: 레조넌스 튜토리얼과 컷인 필살기
8. 1장 클리어 → 자유 탐색 (신전 크리스탈에서 회복 및 기록)

## 그래픽 애셋 파이프라인 (`tools/assetgen`)

모든 그래픽은 Python 생성기로 PNG 애셋을 만들어 `public/assets/`에 굽습니다. 엔진은 이 애셋을 불러와 렌더만 합니다.

| 생성기 | 내용 |
|---|---|
| `sdf.py` | **3D SDF → 도트 렌더러**. 원시도형 결합 모델을 스프라이트 해상도로 레이마칭하고, 색조가 이동하는 명암 램프로 양자화합니다. AO, 깊이 윤곽선, 선택적 외곽선도 처리합니다. |
| `rig.py`, `anims.py`, `humanoid.py` | 스켈레톤 FK와 포즈 라이브러리 (대기/공격/영창/피격/방어/빈사/KO/승리/대시, 필드 3방향 걷기) |
| `characters.py` → `bake.py` | 주인공 4명, NPC, 에코 3종 스프라이트 아틀라스 |
| `monsters.py` → `bake_monsters.py` | 임프, 황혼 늑대, 가시 갑각게, 불꽃 정령, 보스 와이번 |
| `props.py` | 나무·소나무·덤불·풀·꽃·바위·크리스탈·횃불·깃발·옥좌·기둥·풍차·우물 등 |
| `textures.py` | 이음매 없는 도트 지형/건축 텍스처 (텍셀 밀도를 스프라이트와 통일) |
| `backdrop.py` | 원경 산맥과 숲 띠 |
| `fx.py` | 베기, 타격, 화염, 얼음, 번개, 치유, 성광, 암흑, 버프, 브레이크 파편, 마법진, 광선 |
| `portraits.py` | 대화용 도트 초상화 (모델 흉상 + 애니메 눈 페인팅, 표정 5종) |
| `icons.py` | 손으로 찍은 16×16 UI 아이콘 |

```bash
npm run assets      # 전체 재생성 (python3, numpy, pillow, scipy 필요)
```

## 엔진 구조 (`src/`)

- `engine/renderer.js`: HD-2D 후처리 파이프라인 (HDR → 깊이 기반 보케 DOF + 틸트시프트 → 블룸 → ACES, 리프트/감마/게인, 비네트, 색수차, 그레인, 라디얼 블러, 레터박스)
- `engine/sprite.js`: 빌보드 스프라이트 액터 (그림자 투사, 플래시/디졸브/틴트, 에코 영체)
- `world/`: 스플랫 지형과 자동 절벽, 도트 물·폭포, 하늘·구름, 인스턴싱 소품과 바람 흔들림, 3D 건축물
- `battle/`: 전투 규칙(`logic.js`), 연출(`battleScene.js`), 아레나
- `scenes/`: 타이틀, 알현실, 필드, 이벤트 러너
- `ui/`: 전투 HUD, 대화, 메뉴, 튜토리얼, 터치
- `data/`: DB(캐릭터·스킬·에코·적·아이템), 스토리 스크립트, 튜토리얼 문구
- `engine/audio.js`: WebAudio 합성 효과음과 절차적 편곡 BGM (타이틀/성/필드/전투/보스/신전/팡파레)

## 확장 방법

- **챕터 추가**: `data/scripts.js`에 스크립트를 추가하고, 필드 트리거(`scenes/fieldScene.js`의 `TRIGGERS`)에 연결합니다.
- **새 맵**: `world/fieldmap.js`를 본떠 높이 함수와 페인트 함수를 만듭니다.
- **새 캐릭터/몬스터**: `characters.py` / `monsters.py`에 SDF 모델을 정의한 뒤 bake합니다.
- **새 에코**: `data/db.js`의 `ECHOES`에 추가합니다 (보너스, 기술, 레조넌스).
